# VYBE — Modern Music Player UI 🎧

A modern, animated music player interface built with **HTML5 and CSS3**. VYBE features a sleek dark theme, neon lime accents, smooth animations, and a responsive layout designed to create an immersive music experience.

## ✨ Features

- 🎨 Modern dark UI with neon lime accents
- ✨ Smooth CSS animations and transitions
- 💿 Animated album artwork and floating elements
- 🎵 Music discovery section with curated playlists
- 📀 Trending tracks section
- 🎚️ Stylish music player bar UI
- 🌊 Animated sound visualizers
- 🔍 Search bar interface
- 💚 Hover effects on album cards, navigation, and controls
- 📱 Responsive layout for desktop, tablet, and mobile
- ♿ Reduced-motion support for accessibility

## 🛠️ Built With

- HTML5
- CSS3
- CSS Animations and Transitions
- Flexbox and CSS Grid
- Google Fonts — Inter

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/vybe-music-player.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.

No installation or build tools are required.

## ⚠️ Current Status

VYBE is currently a **front-end UI project** built using HTML and CSS only.

The music controls, search, volume, and playlist actions are visual elements and are not yet connected to real functionality. JavaScript and actual audio playback are not included in this version.

## 🎯 Project Goals

This project focuses on practicing modern web design, responsive layouts, CSS animations, visual hierarchy, and interactive hover effects without using JavaScript.
